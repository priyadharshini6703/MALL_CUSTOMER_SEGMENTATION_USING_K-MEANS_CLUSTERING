# Mall Customer Segmentation Using K-Means Clustering

## Description
A machine learning project that segments mall customers into distinct groups based on age, annual income, and spending score using K-Means clustering.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
Mall Customers dataset containing customer age, annual income, and spending score.

## Method
- Data preprocessing
- Feature scaling using StandardScaler
- Elbow Method to determine the optimal number of clusters
- K-Means clustering
- Customer segment visualization
